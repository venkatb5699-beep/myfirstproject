# Luné Parade

A product-listing / party-shop storefront inspired by Misty Daydream-style WooCommerce layouts.

## Run

```bash
npm install
npm run dev
```

## Features

- Home with hero, featured categories, occasions rail, recent & popular products, FAQ
- Shop with search + category/occasion filters
- Product detail with variants, quantity, add to cart
- Cart drawer + cart page (localStorage)
- Welcome promo modal + WhatsApp FAB
